## Технологии

| Что | Где используется |
| --- | --- |
| HTML5 | `index.html` — вся разметка страницы |
| [Bootstrap 5.3](https://getbootstrap.com/) | локально (`css/bootstrap.min.css`) + JS с CDN |
| CSS | `css/custom.css` — небольшие правки поверх Bootstrap |
| Python 3 | `server.py` — простой локальный HTTP-сервер |

Сайт полностью статический: сборка не нужна, JavaScript-фреймворков нет.

## Локальный запуск

Просто открыть `index.html` в браузере — уже достаточно. Если нужен локальный сервер:

```bash
python server.py
```

или на Windows дважды кликнуть `start.bat`. Сайт будет доступен по адресу <http://127.0.0.1:80>.

> Порт `80` может требовать прав администратора. Если сервер не запускается, поменяйте `PORT` в `server.py` на `8000` и откройте <http://127.0.0.1:8000>.

## Публикация

Репозиторий настроен как GitHub Pages: содержимое ветки `main` раздаётся автоматически. Сайт доступен и на GitHub Pages, и на кастомном домене `pikus12345.online` (файл `CNAME`). Чтобы обновить сайт, достаточно закоммитить изменения и запушить:

```bash
git add .
git commit -m "Обновление сайта"
git push
```
